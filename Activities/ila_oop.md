# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
Since there are many variables and functions to note down, we can bind each one to a similar variable inside their own perspective class. This would help us and shorten what we need to code.

### 2. Abstraction
To use abstraction, we should only show the important or essentail peices of code, when debugging, while hiding the important lines of code that make it work. This makes the system beginner friendly and keeps all system easy to use.

### 3. Inheritance
When coding, the code will have some useless parts. Using inheritance will eliminate these pieces and clean the code.

### 4. Polymorphism
When we notice that our code is getting too large, and some lines could be shortened, we use Polymorphism. We change the lines of code, but it's function still stay the same.

## Reflection
The most import pillar in OOP is encapsulation. This is because it helps break down the problem into managable classes. It includes the varaibles and function, and is easy to remmeber when coding. And finally, it helps people easily understand what code they are dealing with, making the coding easier and shorter.
